# Private Markdown report

Phase 6.4 adds `buildMarkdownReport({ scope, findings, summary }, options)` in `src/markdown-report.ts`. It returns private Markdown and shown/omitted group IDs. It does not persist a report, post a comment, create a GitHub check or grant publication permission.

Supply trusted current run scope, v2 findings, a reported run status, coverage counters and optional usage counters. Options require the private artifact root, per-reference authorization callback and current-authority callback; cancellation is supported. The renderer reuses deterministic finding deduplication and authorizes/verifies every referenced artifact, including records later omitted for size. Invalid, missing, expired, cross-scope or unauthorized references prevent report creation. Current authority is checked before/between verification and immediately before return, with a 30-second total wait bound. Expiry is revalidated after asynchronous work.

The report contains immutable PR/SHA/run context, reported progress status, category counts, coverage, optional usage, and finding sections. Sections include expected versus actual behavior, ordered reproduction steps, severity, reported confidence, deployment/target, baseline status, retained record IDs/timestamps, observed per-record metrics and private evidence IDs/digests/expiry. No payload bytes, local storage path, public artifact URL or inline screenshot is emitted. Screenshots remain private references until an authenticated delivery design exists.

Groups are shown by category (confirmed failure, possible regression, advisory, coverage gap), then severity, then deterministic group ID. Grouping never promotes confidence or merges different observations. Shared-evidence relationship counts are reported without claiming a common cause. Record metrics remain separate because attempts may overlap. Coverage requires completed + inconclusive + skipped <= planned and failed <= completed; unaccounted checks remain visible. Reported run completion and an empty finding list never imply a passing test or healthy application.

Narrative fields are rendered in literal Markdown code spans with dynamically sized backtick delimiters. Newlines/control characters and directional override/isolate controls are flattened, preventing supplied text from creating headings, links, images, mentions or executable HTML outside the literal span. Reproduction text is display prose, not a byte-exact payload replay format. Standard CommonMark/GitHub-flavored Markdown rendering is assumed. Redaction remains the trusted producer's responsibility: literal rendering prevents markup interpretation, not disclosure of a secret already present in prose.

The default output limits are 20 groups and 60,000 UTF-8 bytes; configuration allows at most 50 groups and 65,536 bytes. Entire group sections are omitted when they cannot fit, preserving reproduction/evidence sections intact. The footer reports omitted counts, return metadata lists omitted group IDs, and `completeness` becomes `partial`. Totals continue to describe all validated input groups. Verification does not skip omitted groups. A partial report must not be treated as a complete review.

Coverage and usage are supplied by the trusted caller. Reserved cost is labeled an estimate in micro-units, not verified provider billing. Artifact verification establishes authorized stored-reference integrity, not semantic truth of findings, redaction correctness or baseline comparability. This limitation is stated in the report itself. A future aggregator must inspect evidence before publishing assertions.

Tests use real temporary v2 artifact storage and cover deterministic reports, retained reproduction/evidence, literal hostile text, missing coverage/empty findings, group/byte omissions, authorization of omitted records, missing files, stale/cancelled authority, invalid scope/counters, coverage gaps and cost labels. Existing workspace test commands include the suite. No browser or external service is required. GitHub delivery and stale-result reconciliation remain Phases 6.5 and 6.6.
